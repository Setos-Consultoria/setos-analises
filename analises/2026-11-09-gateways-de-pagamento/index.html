Recomendação para o Snack

Critérios: custo por pedido pequeno (≈ R$ 20), Pix barato, recebimento rápido e API com webhook para confirmar o pagamento automaticamente.

1ª opção · menor custo

InfinitePay

Pix com taxa zero e cartão a partir de ~4,20% com recebimento em 1 dia útil. Checkout por link (o cliente paga na página da InfinitePay e volta) com webhook. Contra: API nova e pouco documentada, sem checkout dentro do app e sem boleto.

2ª opção · melhor integração

Mercado Pago

Pix 0,99% na hora e cartão 4,99% (na hora) ou 3,99% (30 dias). Checkout transparente (o cliente paga dentro das telas do Snack, que já existem), SDK Node oficial, ambiente de testes e webhooks maduros. Custa ≈ R$ 0,20 por Pix de R$ 20.

3ª opção · pedir proposta

Pagar.me (Stone)

Cartão 4,19% com recebimento em 1 dia e Pix ~0,99–1,19%, API excelente. Exige aprovação comercial e as taxas são negociadas. Vale cotar quando o volume crescer.

Evitar para ticket baixo: provedores com taxa fixa por Pix (Asaas R$ 0,99–1,99; Vindi mínimo R$ 1,60). Num pedido de R$ 20 isso vira 5% a 10% do valor. Links sem API (Ton, SumUp) também não servem para o Snack, porque não confirmam o pagamento automaticamente no sistema.

Metodologia e ressalvas

  • Pesquisa feita em 09/11/2026 em páginas oficiais dos provedores e em comparativos publicados em 2026. Quando as fontes divergiam, usamos a página oficial; sem página oficial, o valor mais recente e citado por mais de uma fonte.
  • São taxas de tabela (sem negociação). Volume, ramo e tempo de conta mudam o valor; Pagar.me, Cielo, Getnet/Rede e afins trabalham com proposta comercial.
  • "Recebimento" é o prazo para o dinheiro ficar disponível. Prazo curto costuma custar mais; antecipação tem custo à parte.
  • "Integração" avalia o que o Snack precisa: API REST, webhook de confirmação, ambiente de testes (sandbox), SDK para Node.js e possibilidade de pagar sem sair do app (checkout transparente).
  • Antes de contratar, confirme as taxas no painel/contrato do provedor. Esta página não é oferta de nenhum deles e não tem link de afiliado.
