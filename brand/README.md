# Finalistas da marca Setos (09/11/2026)

Escolhidas pelo Matheus entre as cinco propostas. A decisão final entre as duas ainda vai ser feita.

| Proposta | Linha | Fontes | Pasta |
|---|---|---|---|
| **Sombra Fresca** | Original · acolhedor | Fraunces + Figtree | `01-sombra-fresca/` |
| **Cerca Viva** | Tecnológico · sistemas | Sora + Sora + JetBrains Mono | `05-cerca-viva/` |

Cada pasta tem:

- `simbolo.svg` / `simbolo-escuro.svg`: só o símbolo (quadro 64×64)
- `logo.svg` / `logo-escuro.svg`: símbolo + nome (o texto ainda é fonte, não curva)
- `tokens.css`: cores e fontes como variáveis CSS `--setos-*`, tema claro e escuro
- `tokens.json`: os mesmos dados para código (cores, papéis, fontes, contraste)

**Fonte da verdade:** `setos-brand` (`conceitos.mjs` + `node build.mjs`). As cópias em outros repositórios (pasta `brand/`) são só referência: atualize aqui e copie de novo.
